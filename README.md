# theluxverse

Premium digital products store. The Vault. The Edge. The Life.

## Stack

- React + Vite
- Tailwind CSS v3
- shadcn/ui (Radix primitives)
- React Router DOM
- TanStack Query

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

```
src/
├── api/           # API clients
├── components/
│   ├── lux/       # theluxverse brand components
│   └── ui/        # shadcn base components
```
